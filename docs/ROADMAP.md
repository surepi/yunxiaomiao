# MCSM-Shop 开发计划（卡密自助开通平台）

> 架构：MCSManager 面板/守护端 = 运维引擎；网关(8080)+门户(5174) = 品牌店面 + 卡密 + 自动开通。
> 已完成：买家注册/登录、卡密兑换、一键开服、选节点、续费、门户内开关机/重启、SSO 进面板、
> 后台（概览/节点/套餐/卡密/订单/实例）、官方模板一键导入、限流、生产安全自检、webhook 验签、审计修复、
> 买家自助改密/账号页、忘记密码(邮件重置)、服务状态细分（启动中/停止中/操作中）+节点与信息行、后台「直达 MCSM 面板」、
SMTP 邮件通道（开通/续费/到期/重置）、到期生命周期（3天/1天提醒→宽限期→备份→可选自动归档删除）、
卡密批次管理、节点调度权重/容量上限、管理员操作审计、买家门户屏蔽面板超管账号。

图例：P0=开卖前必做  P1=上线初期  P2=规模化/自动化  P3=可选增强

---

## P0 上线前必备（部署 / 安全 / 品牌 / 数据）
- [ ] 云服务器正式部署：Caddy(HTTPS+反代) + systemd 托管网关与门户静态站；门户配 SPA `try_files` 回退（/console /services 刷新正常）
- [ ] 生产环境变量全部换强密钥（JWT_*、WEBHOOK_SECRET、ADMIN_PASSWORD、CORS_ORIGIN 钉域名、PANEL_API_KEY）——启动自检会强制拦截弱配置
- [ ] 3 台 9950X 守护端接入面板，公网 WSS 域名 + Caddy TLS；面板里把节点备注成易读名（如 华东-9950X-01），买家选节点才看得懂
- [ ] 品牌白标：门户换 品牌名 / logo / 域名 / 标题 / 页脚 / 文案；MCSM 面板做轻量 logo+标题替换（保留 LICENSE）
- [ ] 数据备份：SQLite(gateway.db) 与面板 data/ 定时备份脚本 + 一次恢复演练
- [ ] 清理 dev 测试数据（测试套餐 valid/AuditTmp、测试卡密、测试订单）
- 验收：https 域名可访问、强密码登录、3 节点在线、备份可还原、全程只见自有品牌

## P1 自助与售后（减少客服）
- [x] 买家个人中心：自助修改密码（校验旧密码后用管理员 apiKey 重置）、账号页（`/account`）
- [x] 忘记密码 / 找回（注册登记邮箱，SMTP 发送一次性重置链接，`/reset` 落地页，防枚举）
- [x] “我的服务”增强：运行状态细分（运行中/启动中/停止中/操作中/已到期）、展示节点名与面板信息行、连接地址一键复制
  - 注：实时 CPU/内存占用需网关桥接面板 WebSocket（instance stream），列入 P5 可观测
- [x] 后台增加“直达 MCSM 运维”入口（新标签打开面板，地址取 `MCSM_UI_ORIGIN`，方案A）
- 验收：买家改密/查状态不用找客服；客服只在异常时介入

## P2 到期生命周期 + 通知通道
- [x] SMTP 邮件通道（env 配置、可开关，未配置时仅记日志不阻断流程）：开通成功、续费成功、到期提醒、找回密码
- [x] 到期前提醒（3 天 / 1 天），站内倒计时高亮 + 邮件（续费后自动重置提醒标记）
- [x] 超期处理：面板自动停服（已有）→ 宽限期（`GRACE_PERIOD_DAYS` 可配）→ 自动归档/删除实例（reconcile 定时任务，`AUTO_DELETE_EXPIRED` 开关，默认关）
  - 删除前写元数据快照到 `BACKUP_DIR`，并发到期/宽限/清理三封邮件；`DELETE_INSTANCE_FILES` 默认关（守护端文件保留作人工兜底，完整游戏文件备份列入后续）
- [x] 门户“我的服务”临期高亮、到期置灰、续费引导
- 验收：到期自动提醒、超期自动清理、全程无需人工

## P3 淘宝 / ERP 自动发货闭环
- [ ] 对接淘宝 TOP 或聚水潭 ERP（需店铺授权凭证）：订单付款事件
- [ ] 付款 → 自动取卡/发卡（官方自动发货 OR 网关回传卡密/账号），幂等 + 失败重试 + 对账
- [ ] 后台订单与店铺订单关联、发货状态、失败告警
- [ ] 库存售罄自动提醒/联动下架（概览预警已做，接补货流程）
- 依赖：淘宝/ERP 接口权限；webhook 验签与落库已就绪
- 验收：买家拍下付款后无人值守收到卡密/账号，异常有告警可重试

## P4 后台与运营增强
- [x] 订单/实例 搜索与筛选：后台订单（用户名/订单号 + 状态 + 日期范围）、实例（用户名/实例ID/节点 + 状态）可筛选，状态徽标统一中文
- [x] 卡密批次管理：批次汇总视图、按批次筛选/导出未用卡密 CSV、整批停用/启用（已用卡密不受影响）；低库存阈值按套餐可配（套餐 `lowStock` 字段）
- [x] 公告 / 维护通知（门户横幅，后台「公告」标签可增删改；支持级别/定时上下架/停用，买家可关闭）
- [x] webhook 事件查看页（后台「Webhook」标签：按来源/验签/处理状态筛选，可展开查看原始报文）
- [x] 节点容量上限 / 调度权重（`NodeConfig`：权重为相对容量倍数、实例上限硬顶、可临时移出自动调度；自动选节点按「负载 ÷ 权重」均衡）
- [x] 操作日志/审计（`AdminAuditLog`：后台所有 POST/PUT/DELETE 自动记录管理员/路径/状态码/请求快照（密码脱敏），后台「操作日志」标签可查）

## P5 健壮性与可观测
- [ ] 节点掉线/网关异常告警；进程守护（systemd Restart 已具备）
- [x] 登录锁定策略：同一账号连续失败 N 次（`LOGIN_MAX_FAILURES`，默认 5）锁定 M 分钟（`LOGIN_LOCKOUT_MINUTES`，默认 15），买家/管理员命名空间独立、用户名大小写不敏感；叠加已有按 IP 限流
- [ ] 并发兑换/重复提交压测；必要时切换 MySQL
- [x] 安全收口：买家门户禁止 MCSM 超管账号登录（`BUYER_RESERVED_USERNAMES` 默认拦截 root，且面板 permission≥10 账号拒绝发买家令牌）；后台硬编码文案统一走 i18n，网关错误码前端本地化

## 关键依赖
- SMTP 服务（邮箱/短信）：找回密码、各类通知的前提
- 淘宝 TOP / 聚水潭 ERP 授权：自动发货闭环的前提
- 3 台物理机公网域名 + 证书：多节点上线前提

## 建议推进顺序
P0（能正式开卖）→ P1 自助改密（立减客服）→ P2 通知+到期自动化 → P3 淘宝自动发货 → P4/P5 持续打磨
